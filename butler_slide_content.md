## Slide 3: AST-Validated Script Sandboxing and Trust Scoring
Unlike conventional automation tools that execute user-submitted macros blindly, Butler AI passes every script through an Abstract Syntax Tree (AST) validator before sandboxed dry-run execution. This static analysis engine automatically intercepts dangerous system calls, file deletion routines, and unauthorized socket imports, assigning a dynamic trust score to every workflow.

| Trust Score Tier | Security Assessment | Automated Action |
| :--- | :--- | :--- |
| **Green (>90%)** | Fully verified syntax; safe local execution. | Permitted for one-click execution and scheduled background runs. |
| **Yellow (70-90%)** | Minor warnings detected; isolated dependencies. | Requires sandboxed dry-run verification prior to activation. |
| **Red (<70%)** | Prohibited system calls or unverified imports. | Quarantined immediately to protect local system integrity. |
